# 甲烷减排挖矿

> **一句话定义：** 用本会排放或点燃的甲烷（垃圾填埋场、油气田）供能的比特币挖矿：更完全地燃烧强温室气体，并用挖矿收入资助捕获——挖矿可能在排放上为净收益的唯一场景。

**英文原名：** Methane Mitigation Mining
