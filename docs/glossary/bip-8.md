# BIP-8（按高度锁定版）

> **一句话定义：** 提议的软分叉激活机制：以区块高度（而非时间戳）度量部署窗口，LOT 旗可保证激活。从未用于主网，却是 2017 年以来每次激活辩论的核心。

**英文原名：** BIP-8 (Version Bits with Lock-in by Height)
