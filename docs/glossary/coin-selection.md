# 硬币选择（Coin Selection）

> **一句话定义：** 构造交易时挑选花费哪些 UTXO 的钱包工程问题。它决定手续费、决定有没有找零、也决定你的哪些地址被公开关联。

**英文原名：** Coin Selection
