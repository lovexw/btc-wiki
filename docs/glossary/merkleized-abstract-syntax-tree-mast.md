# MAST（默克尔化抽象语法树）

> **一句话定义：** 基于 Taproot 的技术：把每个脚本分支放进默克尔树，未用分支隐藏不显，兼顾隐私与效率。

**英文原名：** Merkleized Abstract Syntax Tree (MAST)
