# 静默支付（Silent Payments）

> **一句话定义：** BIP-352 方案：收款方只公布一个可复用支付码，每笔支付都落到全新的链上地址。无需通知交易、无需交互、无地址复用；代价是收款方要扫描链条。

**英文原名：** Silent Payments
