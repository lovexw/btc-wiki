# P2SH（付给脚本哈希）

> **一句话定义：** 比特币第一次主要地址格式升级（BIP 16，2012）：收款方公布脚本短哈希（地址 3 开头），花费时才揭示完整脚本。

**英文原名：** P2SH (Pay to Script Hash)
