# 比特币 SV（BSV）

> **一句话定义：** 2018 年 Bitcoin Cash 的硬分叉——「分叉的分叉」，由 Craig Wright 与 Calvin Ayre 以「中本聪愿景」之名领导；以超大区块、与 BCH 的哈希战、交易所下架及 Wright 已被证伪的中本聪身份主张闻名。

**英文原名：** Bitcoin SV (BSV)
