# UTXO 池（UTXO Pool）

> **一句话定义：** 钱包控制、可用于构建交易的未花费输出集合。它的形状——几枚大币还是许多小币——决定你未来的手续费，以及花费时有多少历史被关联。

**英文原名：** UTXO Pool
