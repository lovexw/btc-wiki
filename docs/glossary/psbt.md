# PSBT（部分签名比特币交易）

> **一句话定义：** BIP 174 标准格式：在多台设备或共签人之间传递未完全签名的交易而不暴露私钥。让现代自我托管真正可操作的工作流标准。

**英文原名：** PSBT (Partially Signed Bitcoin Transaction)
