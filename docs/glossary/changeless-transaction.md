# 无找零交易（Changeless Transaction）

> **一句话定义：** 输入与付款额足够贴近、无需找零输出的交易；小额超出归矿工作手续费。构建更省、日后花起来更省，且让找零识别无迹可循。

**英文原名：** Changeless Transaction
